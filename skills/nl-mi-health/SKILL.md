# 小米运动健康

处理以 `/nl-mi-health` 开头的小米运动健康数据请求。将同步、查看和汇总保持为一个自然语言工作流，不要求用户记忆命令或提供技术参数。

## 首次使用

1. 检查 Node.js 和 Google Chrome 是否可用；缺少系统级前提时，说明具体缺失项并请求用户安装，不要擅自安装系统软件。
2. 自动安装 Skill 随附的运行依赖；只在首次使用或依赖缺失时执行。
3. 在需要授权时打开可见浏览器，让用户本人完成账号登录、验证码和安全确认；不要要求用户在对话中粘贴密码、验证码、Cookie 或 Token。
4. 授权完成后继续原本的同步、查询或汇总请求。

## 可以处理的请求

| 用户意图 | 处理方式 |
| --- | --- |
| `/nl-mi-health 同步我的数据` | 同步当前账号可访问的健康记录与运动摘要；首次同步后，后续请求自动增量更新。 |
| `/nl-mi-health 我的数据同步好了吗？` | 查看本地同步状态、数据时间范围和最近错误。 |
| `/nl-mi-health 生成最近一周的健康周报` | 基于已同步数据生成最近完整自然日的周报；用户要求时先同步再生成。 |
| `/nl-mi-health 我最近几个月睡眠怎么样？` | 按问题的时间范围汇总睡眠、步数、心率或运动数据，并清楚标注数据缺口。 |
| `/nl-mi-health 重新登录小米账号` | 启动可见浏览器登录流程，等待用户本人完成授权。 |

## 回答原则

- 先理解用户的自然语言时间范围；对“最近几天”“几个月”“几年”选择合适的汇总粒度。
- 用户未要求“先同步再看”时，直接基于已同步数据回答，并说明数据的新鲜度或缺口。
- 将“完整同步”解释为当前账号和区域中小米云端实际返回的数据；不要声称能恢复云端未返回或已删除的内容。
- 不默认删除授权信息或本地健康数据。
- 仅在用户明确询问实现、存储位置或命令参数时，才读取并解释 Skill 附带的技术资料；正常使用时不展开这些细节。
